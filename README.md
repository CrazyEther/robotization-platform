# Контур автоматизации

Платформа для выбора автоматизации бизнес-процессов и оценки инвестиционных решений.

**Объект и бизнес-цель → сравнение решений → экономика → визуализация процесса.**

## Возможности

- Каталог 44 решений в 16 направлениях: складская логистика, хранение, уборка, производственные ячейки, машинное зрение, больничные доставки и цифровые процессы.
- Сравнение характеристик с единицами измерения, условиями применимости и первичными источниками.
- Расчёт CAPEX, OPEX, чистого эффекта, окупаемости, ROI, TCO и NPV по введённым данным.
- Шесть моделей процессов и воспроизведение событий с показателями загрузки и очередей.
- Импорт JSON, CSV и XLSX, сохранение сценариев, экспорт и история версий.
- Организации, роли и приватные сценарии при подключении Supabase.

## Запуск

Установите Node.js 24 или новее.

```sh
npm ci
npm run build
npm start
```

Откройте http://127.0.0.1:8787. Для разработки используйте `npm run dev`.

Для подключения кабинетов и Google OAuth следуйте [инструкции развёртывания](docs/deployment.md).

## Данные и расчёты

Каталог хранит происхождение сведений и отделяет заявления производителей от измерений на объекте. Неизвестные параметры не подставляются автоматически. Для экономической оценки нужны фактические нагрузки, затраты и коммерческие условия выбранной конфигурации. Модельная оценка не является гарантией результата внедрения.

[Исследование процессов и рынка](docs/research-report.md) · [Методика расчётов](docs/models.md) · [API и база данных](docs/backend.md)

## Проверки

```sh
npm run typecheck
npm run lint
npm test
npm run data:verify
npx playwright install chromium
npm run test:e2e
```

Браузерные проверки требуют отдельно запущенного приложения. Проверка локальной БД и восстановления: `npx tsx scripts/verify-database.ts --restore` при работающем локальном Supabase.

Полные снимки сторонних источников и приватные данные не распространяются. Условия использования и ссылки на оригиналы хранятся в реестре источников.
