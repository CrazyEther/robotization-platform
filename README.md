# Robot Investment Studio (RIS)

RIS — независимая веб-платформа предварительной оценки роботизации: от выбора объекта до модели транспортной операции и финансового сценария. Это **не сертифицированный цифровой двойник** и **не замена AnyLogic/Gazebo**.

## Публичный ознакомительный просмотр

Сайт: https://ris-public-preview.battle-walleye.workers.dev . Это отдельный Cloudflare Worker в **строго read-only режиме**, а не полноценный рабочий продукт: симуляция, экономические расчёты и кабинеты пользователей на публичном адресе отключены на сервере. Локальный полный интерфейс и вычислительные сервисы по-прежнему запускаются через `npm run start:full`. Требования безопасности и запуска описаны в `docs/cloudflare-preview.md`.

## Что реализовано

Единый интерфейс (без перехода на предыдущий сайт): тип объекта → каталог → редактор планировки → вычислительный эксперимент → финансовый расчёт → экспорт отчёта. Все разделы используют один сценарий в состоянии приложения. Изменение параметров оборудования или планировки аннулирует старые результаты моделирования.

- Четыре демонстрационных отраслевых шаблона: склад, производство, больница и аэропорт. Во всех пока моделируется **одна транспортная операция на одном уровне**, а не всё предприятие.
- Отдельный маркетплейс с 44 проверяемыми по структуре карточками. Большинство численных полей, цена и пригодность для моделирования не подтверждены; не поддерживаемые движком категории не могут быть автоматически добавлены в транспортную симуляцию.
- Редактор 2D-сетки с препятствиями и размещением двух точек. Кратчайший путь рассчитывается по неподвижной клеточной карте с шагом 1 м.
- Отдельный **Python / SimPy** сервис: события поступления заданий, очереди, парк роботов, загрузка/разгрузка, возвратный маршрут и зарядная очередь. Поддерживает 1–100 воспроизводимых прогонов и показывает среднее, стандартное отклонение и приблизительный 95%-й доверительный интервал оценки среднего. Это **не** интервал предсказания отдельной смены и не доказательство точности относительно реального объекта.
- Расчёт CAPEX, годового OPEX, TCO, ROI, NPV и окупаемости **только после симуляции и при сопоставимых объёмах работ и подтверждённых денежных исходных данных**. Для случайного потока ROI/NPV блокируются без минимум пяти прогонов; для серии — также если наблюдавшийся худший прогон или нижняя граница оценки среднего не достигает введённого плана. Рост производительности не переводится в деньги автоматически. Эти статистические ограничения не подтверждают реальный SLA.
- Экспорт входов, результатов, источника каталожной карточки и ограничений в JSON.

## Запуск локально (Windows / Linux / macOS)

Необходимы Node.js 24+, Python 3.11+ и npm.

```bash
npm ci
python -m pip install -r services/simulation/requirements.txt
npm run start:full
```

Команда запускает локальный Node API/сайт и Python SimPy. По умолчанию сайт доступен на http://127.0.0.1:8890, вычислительный сервис — http://127.0.0.1:8900/health. Изменить порты можно через RIS_WEB_PORT / RIS_SIM_PORT. Если оба порта заняты, остановите принадлежащие вам старые процессы либо задайте другие порты.

## Архитектура и развёртывание

`apps/web/Studio.tsx` — единое React/TypeScript приложение, `packages/ris/contracts.ts` — контракт сценария, маршрутная модель и финансовая арифметика. `apps/api/app.ts` валидирует входы и **только на сервере** обращается к `services/simulation/app.py`; ключ вычислительного сервиса в браузер не передаётся.

Cloudflare Workers может обслуживать интерфейс и API, но **не запускает Python / SimPy внутри Worker**. Для открытой публикации требуется отдельно развернуть Python-сервис по HTTPS, настроить `SIMULATION_ENGINE_URL` и секрет `SIMULATION_SERVICE_KEY` в окружении Worker и запустить интеграционные/нагрузочные испытания. Если сервис не подключён, API возвращает 503; результат симуляции не подменяется вымышленными числами. Текущая ветка **не опубликована в Cloudflare**.

Пример команды развертывания контейнера: `docker build -t ris-sim ./services/simulation`. Сервис требует `SIMULATION_SERVICE_KEY`; публиковать его напрямую в интернет без TLS, сетевых ограничений и контроля нагрузки нельзя.

## Ограничения текущей вычислительной модели

- Симуляция поддерживает один транспортный процесс, фиксированный или пуассоновский поток заданий, до 100 мобильных роботов и 15 000 заявок за эксперимент. Другие позиции маркетплейса доступны для просмотра, но недоступны для модельного внедрения.
- Сетка 1 м, статические препятствия и одинаковая скорость движения на всех сегментах. Не моделируются разгоны, торможения, динамические транспортные конфликты, ширина робота, зоны безопасности, лифты, двери и многоэтажные перевозки.
- Указанные скорость, расход энергии, время загрузки и размер батареи являются **настраиваемыми исходными параметрами**, а не удостоверенными характеристиками конкретной модели из каталога. Отчёт не является техническим заключением о совместимости.
- Финансовый эффект рассчитывается только на основе введённых денежных показателей и сопоставимой производственной задачи. Сокращение времени не равно автоматически экономии оплаты труда. Модель не учитывает налоги, график ввода оборудования, нерегулярные капитальные затраты, остаточную стоимость и сложные варианты финансирования.
- Реальные геометрические планы предприятий, CAD/BIM, AnyLogic, Gazebo, Open-RMF, промышленная кинематика и автоматическая валидация по фактическим внедрениям **не интегрированы**. Называть этот модуль «симуляцией уровня AnyLogic» или готовым цифровым двойником неправильно.

Следующий release gate: калибровать отраслевые модели на реальных технологических процессах, добавить физическую проверку геометрии и оборудования, повторные эксперименты по фактическим данным существующего и нового процесса (baseline-vs-robot) с интервалами, нагрузочно проверить вычислительный сервис и подтвердить финансовые допущения с заказчиком.

## Профессиональный движок сценариев JaamSim

Для запуска реальных DES-экспериментов необходима Java 17+ и установленная локально проверенная версия JaamSim 2026-05:

- Установить Node/Python-зависимости согласно инструкции выше.
- Выполнить npm run jaamsim:install и npm run start:full.
- Выбрать транспортного робота, открыть отдельный этап «Сценарии JaamSim», ввести численность персонала и время операции «до», денежные затраты и три сравниваемых размера парка.
- Запустить реальную модель JaamSim, увидеть базовый и пиковый режимы и скачать JSON со всеми входами и результатами.

Источник JaamSim: https://github.com/jaamsim/jaamsim/releases/tag/v2026-05 . JAR скачивается с контролем SHA-256, не входит в Git. Сервис может работать в Docker: docker build -t ris-simulation:jaamsim services/simulation . Для Cloudflare требуется отдельно размещённый Java/Python вычислительный сервис, с TLS, сетевыми ограничениями и секретом.

Точная архитектура, формулы денежного эффекта, проверенные границы и невыполненная физическая интеграция Gazebo/Open-RMF: docs/simulation-adapters.md . JaamSim обеспечивает профессиональный процессный DES, но не является моделированием реального помещения на уровне AnyLogic или Gazebo.

Полные снимки сторонних источников и приватные данные не распространяются. Условия использования и ссылки на оригиналы хранятся в реестре источников.
