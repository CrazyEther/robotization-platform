# Пространственная визуализация

Раздел «Имитация» объединяет пространственную модель объекта и временную модель операций. Для просмотра конструкции доступна модель платформы EFEU, опубликованная SEW‑EURODRIVE. Её геометрия не заменяет конфигурацию выбранного продукта и не используется как источник расчёта окупаемости.

## Модель EFEU

Исходный пакет: [SEW‑EURODRIVE Multimodal AMR Dataset — ROS2 viewer](https://github.com/SEW-Eurodrive-Open-Source/Multimodal_AMR_dataset/tree/main/dataset_rosbag_viewer/ros2/urdf_viewer). Лицензия пакета MIT, © 2025 SEW‑EURODRIVE, Yannick Wunderle, Leon Schönfeld. Полный текст и контрольные суммы сохранены в `public/models/efeu`.

Xacro преобразован в URDF; ссылки на детали сделаны относительными. Камера переводит исходную систему Z-up в Y-up только для отображения. Модель открывается в исходной позиции шарниров. Вымышленные маршруты или параметры работы не добавляются.

Воспроизводимый сборщик: `python scripts/collect-robot-model.py`. Требуется пакет Python `xacro`. Реестр фиксирует версию исходного репозитория, изменения и SHA-256 файлов.

Веб-формат: `node scripts/convert-robot-model.mjs` после установки Chromium через Playwright. Сборщик проверяет промежуточный GLB валидатором Khronos и сжимает геометрию без квантования позиций и упрощения полигонов. Несогласованные нормали исходных деталей пересчитываются из геометрии. Результат и его SHA-256 добавляются в provenance. Для декодирования используется WebAssembly; CSP разрешает только `wasm-unsafe-eval`, не произвольный JavaScript eval.

## Планировка и движение

Импортируется JSON до 10 МБ, версия схемы 1. Координаты — метры, время — секунды, вертикальная ось — Y. Обязательны название, источник, дата наблюдения ISO 8601 и условия использования.

- `bounds.min`, `bounds.max`: противоположные углы области `[x,y,z]`.
- `objects`: идентификатор, название, тип `rack/conveyor/wall/station/zone`, положение центра, размеры и источник.
- `robots`: идентификатор, название, габариты, источник и последовательность наблюдений `samples`.
- Наблюдение: время `at`, положение центра `position` и `sourceRef`.

Объекты показаны габаритными моделями. Временные отметки должны строго возрастать; наблюдения вне заданных границ отклоняются. Воспроизведение не экстраполирует траектории. Между записями показана последняя наблюдаемая позиция; вне окна наблюдения робот скрывается.

Сцена не вычисляет безопасные расстояния и не заменяет проверку физической совместимости, обследование или испытания системы управления.
